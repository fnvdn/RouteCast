# 实验目的

复现 *Patterns Behind Chaos: Forecasting Data Movement for Efficient Large-Scale MoE LLM Inference* 中基于条件概率热图的专家预测机制，并完成两类比较：

1. **论文原始 Cross-token 任务**：使用当前 token 在同一层的专家集合预测下一 decode token 在该层的专家集合；
2. **适配后的 Cross-layer 任务**：使用当前 token 在当前 MoE 层的专家集合预测同一 token 在下一活跃 MoE 层的专家集合。

随后将 RouteCast V3 改为与论文完全相同的 Cross-token 目标，在相同请求划分、相同测试样本和相同预取预算下进行直接比较。

# 参考论文定位

论文发表于 **ACM/IEEE International Symposium on Computer Architecture 2026（ISCA 2026）**，并获得 **ISCA 2026 Best Paper Award**。论文的整体贡献不仅是预测器，还包括大规模 MoE 路由规律分析、wafer-scale 架构、任务分配、模拟器和多 GPU 系统验证。

# 方法复现

## Conditional Heatmap Predictor

在训练请求上按层统计一阶条件概率：

$$
H_l(i,j)=P(e_{t+1,l}=j\mid e_{t,l}=i).
$$

如果当前 token 选择了多个专家，则取对应条件概率行的平均：

$$
\hat{\mathbf p}_{t+1,l}
=\frac{1}{|\mathcal E_{t,l}|}
\sum_{i\in\mathcal E_{t,l}}H_l(i,:),
$$

并在固定预算下选取得分最高的专家：

$$
\hat{\mathcal E}_{t+1,l}
=\operatorname{TopK}(\hat{\mathbf p}_{t+1,l},K).
$$

论文描述的是从每个概率行选取 Top-$n$ 后合并候选，候选总数可能变化。本实验使用多行平均后固定 Top-$K$，目的是在相同预取预算下与 RouteCast 公平比较。

## Cross-layer 适配

保持相同的一阶条件概率算法，仅将统计对象替换为相邻活跃 MoE 层：

$$
H_{l\rightarrow l'}(i,j)
=P(e_{t,l'}=j\mid e_{t,l}=i).
$$

## 划分与公平性

- 每个模型使用前100个请求；
- 使用文件相对路径的 SHA1 哈希进行 request-level 70%/15%/15% 划分；
- 同一请求内的 token 不会跨越训练集、验证集和测试集；
- Heatmap 仅使用训练请求构建；
- RouteCast 与 Heatmap 使用相同测试请求和固定 Top-$K$；
- RouteCast 随机种子为2026，历史长度为16；
- RouteCast 训练3轮，以验证集宏平均原生预算 Recall 选择最佳 checkpoint；
- 最佳 checkpoint 为 epoch 2。

# 结果解释

## 支持的结论

1. 一阶条件概率热图能够从历史专家选择中提取可利用的 Cross-token 相关性；
2. RouteCast 的多尺度历史、两步转移、prefill 请求分布和动态概率融合能够进一步提升预测质量；
3. RouteCast 的提升不是只出现在单一 Qwen 模型：Qwen、DeepSeek 和 Llama 的原生预算 Recall 均提高；
4. DeepSeek 上相对提升最大，说明 RouteCast 对一阶相关性较弱的模型更有价值；
5. Llama 的原生 Top-1 提升较小，必须通过多随机种子验证其稳定性。

## 不能声称的结论

1. 不能写“RouteCast 整体超过 ISCA 2026 Best Paper”；
2. 当前只超过论文中的固定预算 Conditional Heatmap Predictor；
3. 尚未比较端到端吞吐量、stall time、通信量、缓存命中率和系统加速；
4. 当前结果来自每模型100个请求，尚不能代表完整数据集表现；
5. 当前只有 seed=2026，尚无均值、标准差或置信区间；
6. 固定 Top-$K$ Heatmap 是为公平比较构建的版本，与论文硬件系统中可变候选集合并非完全相同。

# 可用于论文的核心表述

> Under an identical request-level split, cross-token prediction target, and native prefetch budget, RouteCast consistently outperforms the conditional-heatmap predictor across Qwen3, DeepSeek-R1, and Llama-4. It improves native-budget recall by 9.38, 9.97, and 1.28 percentage points, respectively, corresponding to a 6.88-point gain in macro-average recall.

更保守的中文表述：

> 在相同的请求级数据划分、Cross-token 预测目标和原生预取预算下，RouteCast 在 Qwen3、DeepSeek-R1 和 Llama-4 上均超过条件概率热图预测器，宏平均原生预算 Recall 提高6.88个百分点。
